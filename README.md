## Visualizations 

This project consists of 4 dashboards

- Overview of the data
This dashboard was created to give a summary of what the data contains, showing some KPI for the data for reference, A few pie graphs showing the different spread of students background numbers. A graph comparing the current performance against the previous exam performance show that both exams had the same pattern but the more resent exam had slightly poorer results. Finally the last two graphs map average exam results by time spent on different student activities.

- Students Habits
This dashboard is a focused look at the student activities in two different ways looking to see if the exam score attained by any student has any relevant with the average amount of time those students spent on various activities. By looking at both the average time spent on an activity but those who got an exam score and the number of students with that exam score that spent time on that activity we get a more detailed picture letting us see both what the bulk of the students were up to and well as the top/bottom scores.

- Background Factors
By comparing the average exam scores of students with different backgrounds I was looking to see if a group from one background did better than other groups such as students having internet access did better than those without access. However the results of this check turned out to be very uniformed as if none of these factors have a significant effect on the results even when filtering them to only those within a range of exam results.

- Detailed Key Factors
Finally I took a close look at 3 different background groups that I thought would have the most effect, Student’s Motivation, Parental involvement & teacher quality. I compared these qualities by graphing there averages exam score against the number of hours studied. As you can see in the graphs the exam results improve by the number of hours studied. While there is a difference between the quality of the involvement it is not by much. The same graph is done as a count instead of an average to again provide a check and a way of judging how reliable the data is.
